# Varad Durge — Personal Site

Founder dossier portfolio for [Varad Durge](https://github.com/VaradDurge) — Founder of [Argus Labs](https://arguslabs.in).

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS v4
- Framer Motion + Lenis

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Content

Edit copy, builds, timeline, and contacts in [`lib/content.ts`](lib/content.ts).

## Deploy

Deploy to Vercel from this repo (`VaradDurge/Varad-Portfolio`). Point `varaddurge.dev` at the deployment when ready.
